# Sample Questions — Campus Opportunity Radar

> **15 golden questions to demonstrate Genie's capabilities in the Genie Space.**
> Add these as "Sample Questions" when configuring the Genie Space.

---

## 🎯 Primary Demo Questions (The Magic Moment)

### Q1: The Golden Question ⭐
```
I'm Arjun Mehta, a 2nd-year CSE student. I know Java and SQL at an intermediate level. My goal is to become an AI Engineer. What campus opportunities should I pursue and in what order to reach my goal?
```

### Q2: What-If — Time Constraint
```
What if Arjun only has 5 hours per week available? Which opportunities can he still pursue to become an AI Engineer?
```

### Q3: What-If — Already Knows Python
```
If Arjun already knew Python at an intermediate level, how would his opportunity path to AI Engineer change?
```

### Q4: What-If — Different Goal
```
What if Arjun wanted to become a Data Scientist instead of an AI Engineer? What different path should he take?
```

---

## 🔍 Skill Gap Analysis Questions

### Q5: Skill Gap for a Specific Role
```
What skills does a student need to qualify for the TechCorp AI Engineer placement, and which campus opportunities teach those skills?
```

### Q6: Student Readiness Check
```
How ready is Vikram Singh (student_id 5) for the QuantumLeap ML Research Engineer placement? What gaps does he need to fill?
```

### Q7: Department-Wide Gaps
```
Which skills are most commonly required by placement companies but least common among CSE students?
```

## 🗺️ Opportunity Discovery Questions

### Q8: Another Student Path
```
Priya Sharma is a 2nd-year CSE student who knows HTML/CSS and JavaScript. She wants to become a Product Manager. What's her best opportunity path?
```

### Q9: Research Matching
```
Which research opportunities can a student with Python and Machine Learning skills apply for? Include the faculty supervisor and what new skills they'd learn.
```

### Q10: Hackathon Readiness
```
Which hackathons can 2nd-year students participate in? For each, list the required skills and which clubs or events can help prepare them.
```

### Q11: Cross-Department Discovery
```
Sneha Reddy is a 2nd-year ECE student interested in IoT Development. What projects, clubs, and events should she explore, and do any lead to relevant placement opportunities?
```

## 👥 Multi-Stakeholder Questions

### Q12: Faculty Perspective
```
Which students are qualified for Dr. Rajesh Kumar's NLP for Indian Languages research? Show their relevant skills and proficiency levels.
```

### Q13: Placement Cell Perspective
```
For the DataPipe Systems Data Engineer role, how many students currently meet at least 60% of the required skills? List the top 5 candidates.
```

### Q14: Club Recruitment
```
The AI/ML Club wants to recruit new members. Which students have the prerequisite skills but haven't yet developed the skills the club teaches?
```
